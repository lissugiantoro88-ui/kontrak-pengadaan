KolomIsi
BNama Pekerjaan (wajib diisi — baris kosong otomatis dilewati)
CNama Planner
DKategori (idealnya: Maintenance / OYSP / Take Over / Tools / Training)
EJenis Kontrak (idealnya: All in / Material / Jasa / Unit Rate / Empowerment / PPHK / Tools)
FEffective Date — tanggal Excel asli, atau teks dd.mm.yyyy / dd-mm-yyyy. Kalau isi kalimat bebas, otomatis dipindah jadi catatan (bukan dipaksa jadi tanggal)
GCatatan Progress (bebas teks)
H–S12 kolom sub-tahap berurutan — isi APA SAJA (selain kosong) kalau sudah selesai, KOSONGKAN kalau belum: Searching, Quotation, Lingkup (KAK), OE, TKDN, Izin Metode, Berkas Procurement, Pre-Bid Meeting, Evaluasi & Negosiasi, LHP, Penetapan Pemenang, Kontrak/PO
TBoleh dikosongkan — app hitung ulang otomatis dari kolom H–S
UCatatan Akhir / Keterangan (bebas teks)
VDisiplin — opsional (idealnya: Static / Rotating / Instrument / Electrical)
WDasar Pengadaan — opsional, teks polos (tidak bisa bawa format tebal/miring dari Excel)
